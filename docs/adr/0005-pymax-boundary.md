# ADR 0005 — Граница PyMax

Статус: принято.

## Контекст

MAX не имеет официального клиентского API. PyMax (`maxapi-python`) — обёртка
над неофициальным протоколом, которая может измениться в любой момент: и сам
протокол, и библиотека.

При этом продукт стоит именно на пользовательской сессии: официальный Bot API
MAX не даёт доступа к личной переписке владельца, ради которой всё и делается.

## Решение

PyMax — **заменяемая зависимость за границей `bridge/max_client/`**.

Правила:

1. Версия прибита точно: `maxapi-python==2.3.1`. Не `>=`, не плавающий `main`.
   Формат провода не является контрактом.
2. Наружу выходят **только собственные датаклассы** (`IncomingMaxMessage`,
   `MessageDeleted`, `ReadMark`, …). PyMax-типы за границу не проходят.
3. Импорты `pymax` не расползаются: их нет ни в `routing/`, ни в `storage/`,
   ни в Telegram-коде.
4. Обращения к приватным атрибутам PyMax собраны в одном месте и каждое
   покрыто regression-тестом.
5. При изменении upstream мост обязан **падать явно**, а не молча терять
   сообщения.

Пункт 5 — главный. Тихая деградация здесь опаснее отказа: сообщение,
незамеченное из-за изменившегося поля, не вернётся никогда.

## Почему не форк

Форк надо сопровождать. Точная версия плюс тонкая граница дают то же самое
дешевле: обновление PyMax становится осознанным шагом с прогоном тестов.

## Почему не официальный MAX Bot API

Он не даёт читать личные диалоги владельца. Это не компромисс по надёжности,
а отсутствие продукта.

## Последствия

* PyMax обновляется вручную, с прогоном контрактных тестов;
* появляется прослойка датаклассов — код, который «просто перекладывает поля»,
  и это нормальная цена;
* становится возможен fake-backend: контрактные тесты гоняют routing без сети
  и без живого MAX;
* сюрприз от upstream превращается в красный тест вместо потерянного сообщения.

## Известное натяжение

Некоторые поля MAX выбрасывает сам PyMax (например `updateTime` у
отредактированного сообщения), и они читаются из сырого payload. Каждое такое
место — это отход от границы, он должен быть перечислен и покрыт тестом,
иначе граница существует только на бумаге.
